# CS2 战队策略沙盘推演系统 - 用户手册与配置指南

## 项目概述
本系统是一个专为 CS2 (反恐精英2) 电竞战队、教练和数据分析师打造的**交互式策略推演与数据分析工具**。系统采用前后端分离架构（路线 A），后端使用 Python + FastAPI + SQLite 提供本地安全的数据处理，前端使用纯 HTML/CSS/JS 实现了现代化的高颜值玻璃态推演 UI。

核心功能包括：
1. **真实数据收集与存储**：支持录入和管理来自真实赛事的战队数据（胜率、地图偏好、H2H 交手记录）。
2. **BP 智能模拟器 (Veto Simulator)**：基于博弈论和历史胜率，智能推荐 Ban/Pick 策略，支持 “What-if” 假设分支预测。
3. **赛局沙盘演练 (Match Sandbox)**：引入经济系统和战术权重（如 Eco/Force/Buy、默认/RUSH 等），进行逐回合的深度概率推演。

## 一、 环境配置与启动说明

本系统设计为本地离线/半离线运行，确保战队战术数据的绝对安全。

### 1. 前置环境要求
- **操作系统**：macOS, Linux 或 Windows (WSL2/Git Bash)。
- **Python 版本**：Python 3.10 或更高版本。
- **浏览器**：推荐使用最新版的 Chrome、Edge 或 Safari，以获得最佳渲染效果。

### 2. 初始环境安装
打开您的终端（Terminal / iTerm2），按照以下步骤操作：

```bash
# 1. 进入项目后端目录
cd /Volumes/数据/Documents/项目/CS站队策略沙盘推演/backend

# 2. 创建 Python 虚拟环境 (隔离依赖，避免污染全局环境)
python3 -m venv venv

# 3. 激活虚拟环境 (macOS/Linux)
source venv/bin/activate
# 若在 Windows (CMD) 下运行： venv\Scripts\activate
# 若在 Windows (PowerShell) 下运行： .\venv\Scripts\Activate.ps1

# 4. 安装后端依赖包 (FastAPI, SQLAlchemy 等)
pip install -r requirements.txt
```

### 3. 数据初始化与日常更新
系统运行依赖于 SQLite 数据库。当您初次使用，或者需要更新最新的赛事数据时：

```bash
# 确保在 backend 目录且虚拟环境已激活
python scraper.py
```
> **说明**：`scraper.py` 是数据更新脚本。当前版本它会清空旧数据并注入我们在代码中预定义的测试级历史数据。在正式应用中，您可以将此脚本修改为对接 HLTV 爬虫库的抓取逻辑。

### 4. 启动服务
```bash
# 确保在 backend 目录且虚拟环境已激活
uvicorn app:app --reload
```
服务启动后，终端会显示类似 `Uvicorn running on http://127.0.0.1:8000` 的提示。

此时，**请不要关闭终端窗口**，打开您的浏览器，访问 [http://127.0.0.1:8000](http://127.0.0.1:8000)，即可进入推演系统。

## 二、 核心功能操作指南

### 模块 1：数据看板 (Dashboard) —— 战前军情室
- **操作方式**：
  - 在页面顶部，您可以使用下拉菜单切换**时间跨度**（如：过去 3 个月、6个月、1年、全部历史）和**数据源**（静态存档数据、实时同步数据）。切换后，系统会自动向底层数据库发起异步查询并重绘所有图表。
  - 选择您想要分析的两支交战队伍（Team A 和 Team B）。
- **面板功能**：
  - **首发阵容 (Roster)**：展示每支队伍的首发5名选手信息，包括角色定位（如指挥、狙击手等）以及选手评分 (Rating)。将鼠标悬停在评分上，可查看 Impact 和 KAST 进阶数据。
  - **H2H (Head-to-Head)**：展示两支队伍在所有地图上的历史交手胜场。
  - **地图偏好 (Map Pool)**：高亮标出队伍的强图（胜率高）和弱图（胜率低/常Ban图）。
  - **现役地图阵营胜率平衡 & 战术平面图双标签页**：
    - **🌐 阵营胜率平衡雷达图**：展示地图在防守方 (CT) 与进攻方 (T) 胜率的平衡性。支持切换数据源（全部战队均值、当前选中的战队 A、战队 B），并且完全关联时间范围和数据类型筛选，动态渲染不同赛程阶段的胜率平衡。
    - **🗺️ 地图战术平面图**：切换至该标签页后，可通过下拉菜单任意切换地图，预览当前地图的矢量战术平面图（包括 A/B 包点、基地位置、主攻战术路线与关键位置标注）。

### 模块 2：BP 模拟器 (Veto Simulator) —— 赛前心理博弈
- **操作方式**：
  1. 确认赛制（如 BO3 或 BO5）。
  2. 点击地图池中的卡片，选择是对该图进行 **Ban（禁用）** 还是 **Pick（选择）**。
- **面板功能**：
  - **AI 策略推荐**：系统会自动计算当前局面下的“最优解”，并在左侧给出推荐列表。
  - **What-If 分析**：当您故意选择一个非推荐项（例如奇招 Pick）时，底部面板会实时展示这个决策会导致最终胜率发生怎样的变化。

### 模块 3：赛局沙盘 (Match Sandbox) —— 临场回合推演
- **操作方式**：完成 BP 后，进入沙盘模式对选定的地图进行逐回合演练。
- **面板功能**：
  - **手动干预参数**：在每一回合开始前，您可以在屏幕下方调整队伍当前的**经济购买策略**（Eco/Force/Buy/AWP）以及**战术风格**（Default/Rush/Push）。
  - **单步模拟**：点击“➡️ 模拟单回合”按钮，系统将根据当前的经济状态、枪械权重和地图优劣势，算出本回合的胜负并更新比分。
  - **战报流与经济条**：右侧动态输出该回合的文字战报；上方大屏幕实时展示双方的累积经济和士气值。连续丢分会导致士气崩溃，进而影响下一回合的翻盘率。
