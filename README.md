# 线性代数可视化学习工具

## 项目简介
使用原生 HTML5 Canvas + JavaScript 开发的交互式数学可视化网页，帮助理解线性代数的核心概念。

## 在线演示
🔗 [点击访问在线演示](https://你的用户名.github.io/linear-algebra-visualizer/)

## 功能模块
- 向量组合与线性组合
- 矩阵线性变换
- 复合变换与矩阵乘法
- 行列式与面积缩放
- 基底变换与过渡矩阵
- 线性方程组与投影空间
- 二次型与特征值椭圆
- 3D 空间变换与正交投影

## 技术栈
- HTML5 Canvas
- 原生 JavaScript
- 自定义数学引擎（向量/矩阵运算、特征值求解）

## 项目背景
北京建筑大学测绘工程专业（智慧城市方向）转专业答辩项目。
